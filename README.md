# 포커 카드 인식기

PC에서 실행 중인 포커 클라이언트 창(Prime Poker, AA Global 등)을 실시간으로 캡처해
카드(숫자+문양)를 읽고, 결과를 온라인 페이지에 실시간으로 보여줍니다.
페이지에서 본인 Google 계정으로 로그인하면 창 선택·미리보기·ROI 지정·시작/정지를 원격으로 할 수 있습니다.

- **라이브 페이지**: https://bgdongtan-vvovv.github.io/poker-card-reader/

```
[내 PC] 게임 창 캡처 → 카드 인식 → Firebase Realtime DB → [GitHub Pages] 라이브 페이지
```

화면 캡처는 PC에서만 가능하므로 인식 프로그램은 PC에서 돌고, 페이지는 결과만 받아 보여줍니다.

## 인식 방식

포커 클라이언트는 카드를 흰 바탕 + 왼쪽 위 숫자/문양으로 그리고, 내 카드 2장은 겹쳐서
앞 카드의 모서리만 보이게 그립니다. 그래서:

1. 흰 카드 영역을 찾고
2. 각 카드의 왼쪽 위 숫자·문양 글자만 잘라내
3. 숫자는 OCR(RapidOCR)로 읽고 — 클라이언트마다 글꼴이 달라도 동작
4. 문양은 색(빨강/검정) + 기준 문양(`glyphs/`) + 모양(볼록도) 판정이 **모두 일치할 때만** 인정합니다.

창 크기가 달라도 동작하며, 가려져서 확실하지 않은 카드는 틀리게 읽지 않고 건너뜁니다.
카드 배치 구조로 **내 카드 / 보드 / 기타(상대 쇼다운)**를 구분합니다.

## 실행

```
pip install -r requirements.txt
python main.py
```

1. 게임 창을 화면에 띄우고 목록에서 선택
2. (선택) "ROI 표시"로 초록 박스를 띄워 감시 영역 지정
3. "테스트 캡처"로 인식 확인 → "시작"으로 실시간 인식

GPU로 그리는 게임은 창이 가려지면 캡처가 검게 나올 수 있으니 게임 창을 가리지 마세요.

## 온라인 발행 설정

쓰기 권한은 서비스 계정 키로만 가능하고, 페이지(누구나)는 `/table` 읽기만 됩니다.
키는 저장소에 올리지 않고 PC의 아래 경로에 둡니다.

```
%USERPROFILE%\.card-reader\service-account.json
```

키가 없으면 프로그램은 로컬 인식만 합니다. 새 PC에서는 Firebase 콘솔 →
프로젝트 설정 → 서비스 계정 → "새 비공개 키 생성"으로 받아 위 경로에 저장하세요.

## 파일

| 파일 | 역할 |
| --- | --- |
| `main.py` | GUI, 캡처 루프, 온라인 발행 연결 |
| `card_reader.py` | 카드 영역 탐지, 숫자(OCR)·문양 인식, 내 카드/보드 구분 |
| `window_capture.py` | 창 목록, 창 캡처(가려진 창 지원 + 화면 캡처 대체) |
| `roi_overlay.py` | 드래그/리사이즈 가능한 초록 ROI 박스 |
| `publisher.py` | Firebase Realtime DB 발행 (상태 + 최근 50개 기록 + 연결 신호) |
| `glyphs/` | 실제 게임 화면에서 추출한 문양 기준 이미지 |
| `docs/index.html` | GitHub Pages 라이브 페이지 |
| `database.rules.json` | DB 보안 규칙 (공개 읽기 `/table`, 클라이언트 쓰기 금지) |
